# 《論語》全文閱讀及翻譯

《論語》是記錄孔子及其弟子言行的一部書，共二十篇，由孔子的弟子及再傳弟子編寫，是我國古代儒家經典著作之一，是首創語錄之體。漢語文章的典範性也發源於此，儒家（在春秋戰國時期與墨家對立）創始人孔子的政治思想核心是“仁”、“禮”和“中庸”。《論語》是記錄孔子主要弟子及其再傳弟子關於孔子言行的一部書。
